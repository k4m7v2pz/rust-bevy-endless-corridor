# 图片处理规范（单张 PNG 优先）

本文档定义本项目的图片制作与命名规范，优先使用单张 PNG 而非精灵图，方便美术维护并保持一致性。

## 1. 格式与色彩
- 统一使用 `PNG`，颜色模式 `RGBA`，每通道 8-bit（PNG-32）。
- 禁止索引色/调色盘（不要保存为 PNG-8）。
- 色域使用 `sRGB`，避免不同软件色差。

## 2. 透明与边缘
- 图片背景必须透明。
- 导出时避免出现黑边/白边或杂色边缘。
- 如果存在半透明边缘，确保在透明背景下预览无杂边。

## 3. 命名规范
- 全小写 + 下划线：`enemy_bomber_idle_01.png`。
- 动画帧使用零填充：`run_01.png`、`run_02.png`。
- 建议结构：`对象_动作_序号.png`。

## 4. 目录归类
- `images/backgrounds`：背景大图
- `images/ui`：按钮与界面
- `images/sprites`：角色/敌人/物件单帧或帧序列
- `images/effects`：特效帧序列
- `images/tiles`：地形切片
- `images/raw`：原始或未整理素材

## 5. 动画帧规范（无精灵图）
- 同一动画的帧必须 **尺寸一致**。
- 同一动画的帧必须 **对齐一致**（锚点一致）。
- 通常使用"脚底对齐"或"中心对齐"作为锚点规则。

## 6. 尺寸与比例
- 图片实际尺寸以像素为准，DPI 无意义。
- 保持"基准比例"一致（例如角色高度 100px）。
- 若需要高分屏支持，可在未来添加 2x/4x 资源目录。

## 7. 性能建议（单图优先下的底线）
- 常用资源可在启动或场景加载时预加载。
- 避免超大图片；必要时拆分。
- 透明区域过大的图片可裁剪为紧致边界，但要保证锚点一致。

## 8. 检查清单
- 是否 PNG-32 (RGBA 8-bit)
- 是否 sRGB
- 是否透明背景且无杂边
- 动画帧尺寸一致
- 动画帧锚点一致
- 命名规范统一
