# 主角精灵设计文档

## 角色概述

- **名称**: 探索者 (Explorer)
- **身份**: 无尽回廊的旅人
- **风格**: RPG Maker 经典 5-6 头身
- **分辨率**: 64x64 (@1x) / 128x128 (@2x)

## 外观描述

身形娇小但敏捷，穿着带兜帽的深色披风，脸部隐没在阴影中。双手空置，为未来道具装备预留空间。

## 动画帧

### 站立 (Idle) - 每方向 2 帧

- 帧 01: 静止姿态
- 帧 02: 呼吸起伏

### 行走 (Walk) - 每方向 3 帧

- 帧 01-03: 行走循环，披风轻微飘动

### 特殊帧

- 交互: 伸手动作 (单帧)
- 受伤: 身体后仰 (1帧)
- 死亡: 跪地姿态 (1帧)

## 精灵表布局

```
64x64 网格布局:

Row 0: 站立下 (2帧) + 行走下 (3帧) = 5格
Row 1: 站立左 (2帧) + 行走左 (3帧) = 5格
Row 2: 站立右 (2帧) + 行走右 (3帧) = 5格
Row 3: 站立上 (2帧) + 行走上 (3帧) = 5格

总计: 4行 x 5列 = 20格 (320x256 像素 @1x)
@2x 版本: 640x512 像素
```

## 设计备注

- 主角双手空置，不预装任何道具
- 油灯/手电筒作为独立道具实体存在
- 装备道具时通过叠加层方式显示
