# 精灵命名规范（单张 PNG 优先）

本规范用于统一精灵图片（单图或帧序列）的文件命名，便于程序自动加载与管理。

## 1. 基本格式

建议格式：
```
<对象>_<动作>_<方向>_<帧序号>.png
```

可选的 2x 版本：
```
<对象>_<动作>_<方向>_<帧序号>@2x.png
```

## 2. 规则
- 全小写英文 + 下划线分隔
- 1x 不写后缀，2x 才写 `@2x`
- 帧序号使用零填充：`01`、`02`、`03`
- 没有方向就省略方向字段
- 没有帧序列（单张）可省略帧序号字段

## 3. 示例
- `player_drive_right_frame_01.png`
- `player_drive_right_frame_01@2x.png`
- `player_idle_01.png`
- `ui_start.png`
- `enemy_bomber_explode_05@2x.png`

## 4. 中文含义对照（常用）
- 主角：`player`
- 行驶：`drive`
- 向右：`right`
- 最开始的帧：`frame_01`

对应示例：
- `player_行驶_向右_最开始的帧` → `player_drive_right_frame_01`

## 5. 一对一原则
- 每张 1x 图可以有一个 `@2x` 对应版本
- 命名必须完全一致，仅差 `@2x` 后缀
