# 功能特性

本文档详细介绍 Narrative Path Craft 引擎的各项功能特性。

## 设计理念

- **开发者友好**：专注于剧情和逻辑代码编写，无需深入美术制作或复杂场景搭建
- **一致性体验**：玩家在不同作品中享受统一的视觉效果和交互体验
- **快速原型**：内置的黑暗覆盖层、照明系统等高级功能，让创意快速变为现实

## 核心特点

- **无战斗系统**：专注于探险、陷阱、对话和剧情，避免数值繁琐
- **AI友好**：JSON配置+Schema验证+显式翻译元数据，便于AI辅助开发
- **合规与包容**：内置警告系统（光敏性癫痫/健康忠告）+多语言支持
- **组件化架构**：使用事件总线实现模块解耦
- **开箱即用**：预置高级视觉效果（黑暗覆盖层、动态照明），降低开发门槛

## 功能特性

### 非线性地图探险
- **视野受限机制**：圆形照明和手电筒照明限制可视范围，增加探索紧张感
- **声音提示系统**：通过环境音效和声音线索引导玩家发现隐藏路径或危险
- **AI突然现身**：敌人可从迷雾中突然出现，创造意外惊吓效果
- **闪烁圆形灯**：固定半径的圆形光照范围，亮度随机波动，营造不稳定的光照视觉效果
- **回环型走廊设计**：地图结构采用环形布局，增强迷宫感和探索深度
- **流畅移动**：采用像素级平滑移动，而非传统的逐格跳跃式移动
- **自然操控**：支持键盘方向键和WASD操作，移动手感顺滑自然

### 内置地图图块美术资源
- **基础图块**：内置地板、墙壁等基础地图图块美术
- **常用物品**：提供常用物品素材，如家具、道具等
- **节省时间**：节省开发者制作剧情和代码的时间，提高开发效率
- **一致性**：确保地图美术风格一致，提升游戏整体视觉效果

### 环境特效系统
一键启用多种环境覆盖层效果：
- **战争迷雾**：经典的探索隐藏机制
- **水下效果**：蓝色调覆盖层+波浪动画
- **毒气效果**：绿色调覆盖层+流动动画
- **魔法光环**：紫色调覆盖层+炫光效果
- **下雨效果**：淡蓝色调覆盖层+雨滴动画+室内外音效差异化
- **吹风效果**：可设定0～359度风向，提供视觉粒子效果+环境音效，并影响主角移动速度或在静止时产生强制位移
- **动态混合**：多种效果可同时叠加，自动计算合成色彩

### 黑暗覆盖层系统
开发者可一键启用全屏黑暗效果，营造紧张氛围：
- **圆形照明**：围绕玩家的圆形可视区域，可自定义半径大小
- **手电筒照明**：扇形光照效果，支持自定义照射半径和角度
- **动态光照**：光照区域实时跟随玩家移动，创造沉浸式探险体验
- **灯光闪烁**：可配置的灯光闪烁效果，用于制造紧张氛围或误导玩家判断
- **开发者友好**：简单API调用即可实现专业级视觉效果

### 双模式UI系统
- **对话模式**：屏幕下方的角色立绘+对话框，用于NPC交互
- **通知模式**：屏幕左上角文字区域，用于显示游戏动作反馈（发现线索、获得物品等）

### 人物立绘模板系统
- **内置模板**：提供一套人物模板作为立绘，包含多个表情变体供开发者选择
- **原创性保障**：确保所有素材为原创，避免使用其他动画片作品的角色，防止侵权
- **多样化选择**：开发者可以根据剧情需要选择合适的人物立绘和表情
- **节省时间**：缩短开发者准备素材的时间，让他们专注于创意和代码

### 低成本人物素材制作
- **AI生成**：使用免费AI工具（如元宝AI）生成素材，降低制作成本
- **开放共享**：不注册版权，允许互联网用户自由二创
- **社区参与**：鼓励开发者和玩家共同参与素材创作和分享
- **质量保证**：确保AI生成的素材质量符合游戏开发需求

### 陷阱与生存系统
- 区域/交互触发陷阱，死亡处理机制

### 分支对话系统
JSON配置驱动，变量控制剧情走向：
- **作者留言区**：游戏内预留专门区域展示开发者创作心得和感谢
- **通关秘籍**：为卡关玩家提供适度提示，平衡挑战性与可达性
- **设计解读**：展示解谜设计背后的创作逻辑，包括数字规律、图形含义等设计思路
- **角色原创标识**：支持标记游戏主角为原创角色或其他动漫的二创角色，便于玩家识别和版权声明

### 多结局剧情
基于玩家选择和游戏状态的多种结局：
- **结局追踪**：游戏内显示总结局数量和当前解锁进度
- **成就系统**：记录已达成结局，激励玩家探索不同剧情分支
- **回放价值**：清晰的结局统计增强游戏重玩性

### 存档系统
7位小写哈希ID唯一标识，双时间维度记录：
- **简洁界面**：列表式存档展示，包含存档时间、游戏进度百分比
- **智能排序**：支持按现实时间排序和按游戏内时间排序两种模式
- **快速操作**：一键保存/读取，支持存档备注和删除
- **安全保障**：自动备份机制，防止存档损坏丢失

### 玩家友好提示
- **视觉分类**：光敏性癫痫、惊吓（文字恐怖/地图图块惊吓/对话立绘惊吓/全屏突脸惊吓，惊吓前会在游戏内通过浮动文字或浮动窗口包含提示信息）、血腥、暴力、强烈的颜色对比、面部扭曲等警告
- **听觉分类**：声音惊吓等警告
- **操作分类**：追逐战、解谜等警告
- **健康游戏提示优化**：提供可选项，将提示变小并颜色变淡，移至屏幕下方作为慢慢提示，不影响其他内容展示，优化用户体验

玩家友好提示会一次性展示大量图标和文字，因此需要玩家确认。玩家友好提示只会在首次游玩游戏时提示一次，之后再次进入游戏不会再打扰玩家。开发者也可以选择不展示这些提示，例如图像惊吓、声音惊吓等，以给玩家带来更神秘的游戏体验，这种情况下游戏不会提前告知可能包含的内容。

### 智能追逐系统
基于物理距离计算的动态追逐机制：
- **智能路径预测**：怪物根据玩家位置和移动方向预判追击路线
- **房间间追踪**：支持跨房间连续追逐，保持紧张感的连贯性
- **动态难度调节**：根据玩家表现实时调整追逐强度和怪物行为

### 跨平台支持
支持在Windows、macOS、Linux平台上开发和运行游戏
